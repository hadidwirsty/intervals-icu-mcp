# /panduan-kekuatan — Panduan Latihan Kekuatan & Perlindungan Struktur

Skill ini memandu pelaksanaan **latihan kekuatan fungsional pelari (*Running-Specific Strength Training*)**. Menggabungkan sains adaptasi neuromuskular Steve Magness, protokol perlindungan tulang belakang *flat lumbar (reduced lordosis)* Dr. Stuart McGill (**McGill Big 3**), serta pemetaan 8 kelompok otot utama dari *Running Anatomy*.

---

## 1. Aturan Baku Penjadwalan: "Hard Days Hard, Easy Days Easy"

Mengacu pada konsensus Marius Bakken, Steve Magness, dan Coach Faris Salman:
- **Jadwal Sesi Penuh (22–25 Menit)**: Dieksekusi **2 kali seminggu pada hari sesi kualitas Sub-Threshold** (Selasa sore & Jumat sore), beberapa jam setelah sesi lari pagi tuntas.
- **DILARANG KERAS**: Melakukan latihan beban berat di hari lari santai (*Easy Days*) atau hari istirahat, untuk menghindari *Medium Fatigue Trap* yang merusak pemulihan seluler dan biogenesis mitokondria.

---

## 2. Struktur Dua Jalur Latihan Kekuatan

### Jalur A: Sesi Penuh 22–25 Menit (Selasa & Jumat Sore)

Sesi ini dirancang dalam 4 blok gerakan fungsional tanpa alat mahal (cukup *resistance band* dan matras):

#### Blok 1: Mobilitas & Aktivasi Hip Flexor (5 Menit)
1. **Standing Banded Knee Drive** (Psoas & Iliacus): 3 set $\times$ 10–12 repetisi/kaki (melatih tarikan lutut saat *early swing*).
2. **90/90 Hip Mobility Flow**: 2 set $\times$ 60 detik rotasi panggul (memperbaiki mobilitas rotasi internal/eksternal panggul).

#### Blok 2: Stabilitas Tulang Belakang — McGill Big 3 (7 Menit)
*Fokus Proteksi Tulang Belakang: Menghindari beban kompresi & rotasi berlebih pada pinggang (bebas fleksi berulang). DILARANG sit-up, crunches, atau Russian twist berbeban kompresi tinggi!*
1. **McGill Modified Curl-Up**: 3 set $\times$ penahanan 8–10 detik per sisi (satu lutut ditekuk, tangan menyangga kurva lumbar, kepala terangkat 2–3 cm tanpa melengkungkan leher).
2. **Side Plank (Quadratus Lumborum & Glute Med)**: 3 set $\times$ penahanan 15–20 detik per sisi (menahan panggul tetap sejajar lurus).
3. **Bird-Dog (Erector Spinae & Kontrol Anti-Rotasi)**: 3 set $\times$ 8–10 repetisi per sisi dengan jeda henti 3 detik di puncak (kaki dan lengan berlawanan lurus tanpa memutar panggul).

#### Blok 3: Penguatan Rantai Kinetik Tungkai Bawah (8 Menit)
1. **Bent-Knee Calf Raise (Soleus Armor)**: 3 set $\times$ 15–20 repetisi (lutut tertekuk $45^\circ$, melatih Soleus yang menopang gaya **6–8x berat badan** saat lari).
2. **Single-Leg Romanian Deadlift (Hamstring Eccentric)**: 3 set $\times$ 8–10 repetisi/kaki (mencegah cedera *terminal swing*).
3. **Bulgarian Split Squat / Reverse Lunge (Quadriceps Eccentric)**: 3 set $\times$ 8–10 repetisi/kaki (meredam gaya impak mendarat).
4. **Side-Lying Clamshell / Banded Lateral Walk (Gluteus Medius)**: 3 set $\times$ 15 repetisi/kaki (mencegah *Trendelenburg sign* / lutut kolaps ke dalam).

#### Blok 4: Elastisitas Tendon & Reaktivitas Pegas (3 Menit)
1. **Pogo Hops (Achilles Stiffness)**: 2 set $\times$ 20 detik lompatan elastis dari pergelangan kaki (kontak tanah sesingkat mungkin).
2. **Wall Lean Tibialis Raises**: 2 set $\times$ 20 repetisi (mengangkat ujung jari kaki untuk memperkuat otot tulang kering dan menangkal *shin splints*).

---

### Jalur B: Daily Micro-Dosing Pra-Lari (3–5 Menit Harian)

Dilakukan setiap pagi sebelum melangkah keluar pintu rumah:
1. **20x Wall Tibialis Raises**: Memompa aliran darah ke tulang kering.
2. **15x Bent-Knee Calf Raises per kaki**: Mengaktifkan Soleus sebelum menerima beban impak lari.
3. **5x Bird-Dog per sisi**: Mengunci stabilisasi postur inti (*Stay Tall When Tired*).
